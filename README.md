# SNS Assignment-1: Steganography

## Introduction
Steganography is the technique of hiding secret information inside an ordinary file, such as an image, so that the presence of the message is concealed.

## Objective
To demonstrate image steganography using the Least Significant Bit (LSB) technique.

## Working
- Convert the secret letter into 8-bit binary using ASCII.
- Use a key and a position formula to select image pixels.
- Replace the least significant bit of each selected pixel with one message bit.
- Recover the hidden letter by reading the least significant bits in the correct order.
- Attempt to discover the key through systematic testing.

## Concepts Used
- Image steganography
- Least Significant Bit (LSB)
- ASCII and binary conversion
- Key-based pixel selection
- Message encoding and decoding
